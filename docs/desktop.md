# Desktop inspector

AgentTrace includes a Tauri v2 + React desktop inspector under `apps/desktop`.

The desktop app is a local visualization layer over the same SQLite trace format used by the CLI. It does not require a hosted backend or a localhost API process.

## Features

- run browser with status, harness, timestamp, and local bookmarks;
- live event/stat/artifact refresh while the selected run is active;
- event timeline with category filters and text search;
- complete capability evidence strip from the product adapter registry, including explicit unavailable categories;
- explicit native / inferred / derived / unavailable provenance badges;
- payload, raw-source, execution, terminal, diff, and relations inspectors;
- terminal evidence only for shell/process events or events with structured command metadata;
- unified and side-by-side diff rendering only when the trace actually exposes recognizable patch/diff text;
- span tree only from real `span_id` / `parent_span_id` relationships;
- subagent and context-provenance views only from explicit normalized lifecycle events;
- command, filesystem-impact, token, cost, duration, retry, and error views when the trace contains those fields;
- deterministic run comparison for event/usage-sample/retry/error measurements without an LLM-generated winner;
- sanitized JSONL export generated by the Rust backend;
- artifact metadata view with run/event linkage, size, type, compression state, and SHA-256 identity;
- raw-source visibility toggle for local debugging;
- compact dark DevTools-style layout intended for high-density debugging rather than decorative dashboards.

When evidence is absent, the relevant panel says `unavailable`; the frontend does not infer a patch, span, subagent, context change, terminal log, or capability merely to fill the screen.

## Development

Install frontend dependencies and start Tauri from `apps/desktop`:

```bash
npm install
npm run tauri dev
```

The Tauri crate is deliberately isolated from the root Rust workspace because the desktop runtime may require a newer Rust compiler than the AgentTrace core MSRV.

## Database selection

The desktop shell uses `AGENTTRACE_DB` when that environment variable is set. Otherwise it creates or opens `agenttrace.db` in the platform-specific AgentTrace application-data directory.

To inspect the same database as a CLI session, point `AGENTTRACE_DB` at the CLI database before launching the desktop app.

## Redaction profile

Set `AGENTTRACE_REDACTION_CONFIG` to the same additive JSON profile used by the CLI when organization-specific patterns are required:

```bash
AGENTTRACE_DB=/path/to/agenttrace.db \
AGENTTRACE_REDACTION_CONFIG=/path/to/agenttrace-redaction.json \
  npm run tauri dev
```

The Rust Tauri layer re-applies that policy before returning events or sanitized exports to React. Built-in safe rules remain enabled even when a custom profile is present.

## Trust model

The desktop app displays stored evidence. It does not reinterpret unavailable fields as observed telemetry. Raw-source views show only what was retained after persistence and the current desktop redaction pass.

Artifact bytes are not automatically loaded into the React UI; the current relations panel exposes metadata only. This avoids turning the inspector into an implicit arbitrary-file exfiltration surface.
